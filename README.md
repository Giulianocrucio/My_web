# Rocket Landing AI
https://giulianocrucio.github.io/My_web/

A browser-based simulation where rockets learn to land using **neural networks** and a **genetic algorithm**, all built from scratch with **JavaScript**, **HTML**, and the **Matter.js** physics engine.

Each rocket has 3 binary thrusters (left, right, center) and a neural network that takes physical state inputs (like orientation, velocity, distance from ground) to decide how to land. Rockets evolve over generations, improving through selection, crossover, and mutation based on landing performance.

Includes a real-time training environment, user-adjustable parameters (mutation rate, survival percentage), and a graph showing learning progress.

> A personal project to apply AI concepts hands-on and improve programming skills through simulation and visualization.
